# 商城团购功能开发文档

## 📋 文档概述

本文档描述基于现有 Big Event 社区平台扩展的商城团购功能，包括商品管理、团购活动、秒杀抢券、订单支付等核心模块。遵循 RESTful API 设计风格，结合 Redis 缓存、分布式锁、幂等性控制、数据库事务等高并发场景优化策略。

**版本**：v1.0
**更新时间**：2026-09-03
**作者**：开发团队

---

## 🎯 功能模块

### 1. 商品管理模块
- 商品发布（图文/视频，支持 SKU 维度）
- 商品分类（商家分类/系统分类）
- 商品库存管理（实时库存）
- 商品上下架管理
- 商品搜索与推荐

### 2. 团购活动模块
- 创建团购活动（设置团购价、人数门槛、时间限制）
- 团购商品列表与详情
- 团购人数统计与进度展示
- 团购活动结束处理（订单自动关闭）

### 3. 秒杀抢券模块
- 抢购优惠券（限时限量）
- 优惠券预扣库存（Redis 乐观锁）
- 瞬时抢购高并发处理
- 抢购记录与防刷

### 4. 订单系统模块
- 下单（团购订单/秒杀订单）
- 支付回调处理
- 订单状态流转（待支付→待发货→已完成/退款）
- 订单查询与导出
- 退款/售后处理

### 5. 用户中心模块
- 我的订单（历史订单、退款记录）
- 我的团购（参与团购、团购进度）
- 我的优惠券（可用/已用/过期）
- 收货地址管理
- 消息通知（订单状态变更、通知推送）

### 6. 商家管理模块
- 商家认证申请（上传营业执照、身份信息）
- 商家信息管理（店铺名称、描述、头像）
- 商家商品管理（发布商品、上下架、库存管理）
- 商家团购管理（创建团购活动、参与人数统计）
- 商家优惠券管理（创建优惠券、发放、统计）
- 商家订单管理（查看买家订单、发货、退款处理）
- 商家数据统计（销售额、订单量、商品销量）

```sql
-- 商品分类表
CREATE TABLE `product_category` (
  `id` INT PRIMARY KEY AUTO_INCREMENT COMMENT '分类ID',

  `parent_id` INT DEFAULT 0 COMMENT '父分类ID',
  `icon` VARCHAR(255) COMMENT '分类图标',

  INDEX `idx_parent_id` (`parent_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品分类表';

-- 商品基本信息表
CREATE TABLE `product` (
  `id` INT PRIMARY KEY AUTO_INCREMENT COMMENT '商品ID',
  `name` VARCHAR(200) NOT NULL COMMENT '商品名称',
  `category_id` INT NOT NULL COMMENT '分类ID',
  `cover_img` VARCHAR(500) NOT NULL COMMENT '封面图',
  `images` TEXT COMMENT '详情图(JSON数组)',
  `description` TEXT COMMENT '商品详情',
  `price` DECIMAL(10,2) NOT NULL COMMENT '原价',
  `market_price` DECIMAL(10,2) DEFAULT 0 COMMENT '市场价',
  `status` TINYINT DEFAULT 1 COMMENT '状态(1=上架,0=下架)',
  `stock` INT DEFAULT 0 COMMENT '总库存',
  `sales_count` INT DEFAULT 0 COMMENT '销量',
  `view_count` INT DEFAULT 0 COMMENT '浏览量',
  `create_user_id` INT COMMENT '创建者ID',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX `idx_category_id` (`category_id`),
  INDEX `idx_status` (`status`),
  INDEX `idx_create_time` (`create_time`),
  INDEX `idx_sales` (`sales_count`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品表';

-- 商品SKU表（支持规格、库存）
CREATE TABLE `product_sku` (
  `id` INT PRIMARY KEY AUTO_INCREMENT COMMENT 'SKU ID',
  `product_id` INT NOT NULL COMMENT '商品ID',
  `sku_name` VARCHAR(100) NOT NULL COMMENT 'SKU名称(如:红/XXL)',
  `spec_values` JSON COMMENT '规格值(JSON数组)',
  `price` DECIMAL(10,2) NOT NULL COMMENT 'SKU价格',
  `stock` INT DEFAULT 0 COMMENT 'SKU库存',
  `sales_count` INT DEFAULT 0 COMMENT '销量',
  INDEX `idx_product_id` (`product_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品SKU表';
```

## 🔒 幂等性设计

### 1. Token 幂等（推荐）

**原理**：使用客户端生成的唯一 ID（如 UUID）作为幂等键，服务端 Redis 存储已处理的键，重复请求时返回缓存结果。

**实现**：

```java
@RestController
@RequestMapping("/order")
public class OrderController {

    @Autowired
    private StringRedisTemplate stringRedisTemplate;

    @Autowired
    private OrderService orderService;

    /**
     * 创建订单（幂等）
     * @param order 订单数据
     * @param idempotencyKey 幂等键（客户端生成UUID）
     */
    @PostMapping
    public Result<Order> createOrder(
            @RequestBody Order order,
            @RequestHeader("Idempotency-Key") String idempotencyKey) {

        // 1. 生成幂等键（服务端兜底）
        if (StringUtils.isEmpty(idempotencyKey)) {
            idempotencyKey = UUID.randomUUID().toString();
        }

        String key = "idempotent:order:" + idempotencyKey;

        // 2. 检查幂等键是否存在
        Boolean exists = stringRedisTemplate.hasKey(key);
        if (Boolean.TRUE.equals(exists)) {
            // 幂等键已存在，返回缓存的订单数据
            String cachedOrder = stringRedisTemplate.opsForValue().get(key);
            return Result.success(JSON.parseObject(cachedOrder, Order.class));
        }

        // 3. 执行业务逻辑
        Order createdOrder = orderService.createOrder(order);

        // 4. 存储幂等键（有效期 1 小时）
        stringRedisTemplate.opsForValue().set(
            key,
            JSON.toJSONString(createdOrder),
            1, TimeUnit.HOURS
        );

        return Result.success(createdOrder);
    }
}
```

### 3. 状态机幂等

**原理**：通过状态机保证订单状态流转的唯一性。

```java
@Service
public class OrderStateMachine {

    // 订单状态流转规则
    private static final Map<OrderStatus, Set<OrderStatus>> TRANSITIONS = new HashMap<>();
    static {
        TRANSITIONS.put(OrderStatus.PENDING, EnumSet.of(OrderStatus.PAID, OrderStatus.CANCELLED));
        TRANSITIONS.put(OrderStatus.PAID, EnumSet.of(OrderStatus.SHIPPED, OrderStatus.REFUNDING));
        TRANSITIONS.put(OrderStatus.SHIPPED, EnumSet.of(OrderStatus.COMPLETED));
        TRANSITIONS.put(OrderStatus.REFUNDING, EnumSet.of(OrderStatus.REFUNDED, OrderStatus.CANCELLED));
    }

    /**
     * 转换订单状态（幂等）
     */
    public boolean transition(Order order, OrderStatus newStatus, String reason) {
        Set<OrderStatus> allowed = TRANSITIONS.get(order.getStatus());
        if (allowed == null || !allowed.contains(newStatus)) {
            throw new IllegalStateException("非法状态流转: " + order.getStatus() + " -> " + newStatus);
        }

        order.setStatus(newStatus);
        order.setUpdateTime(new Date());
        orderMapper.update(order);

        // 状态变更通知（MQ + WebSocket）
        mqProducer.sendStatusMessage(order);
        websocketService.notifyStatusChange(order.getUserId(), order.getId(), newStatus);

        return true;
    }
}
```

## ⚡ 秒杀抢券高并发方案

### 1. 预扣库存（Redis 乐观锁）

**核心思想**：使用 Redis `decr` + Lua 脚本保证原子性，防止超卖。

#### Redis Lua 脚本实现

```lua
-- stock.lua
local key = KEYS[1]  -- 缓存 key: coupon_stock:{id}
local userId = ARGV[1]  -- 用户ID
local quantity = tonumber(ARGV[2])  -- 抢购数量

-- 检查库存
local remain = redis.call('get', key)
if remain == nil or remain < quantity then
    return -1  -- 库存不足
end

-- 原子扣减库存
local stock = redis.call('decrby', key, quantity)
redis.call('expire', key, 3600)  -- 1小时后过期

-- 记录抢购记录
local recordKey = 'coupon:record:' .. userId
redis.call('sadd', recordKey, ARGV[2])

return stock  -- 返回剩余库存
```

**Java 调用示例**：

```java
@Service
public class CouponGrabService {

    @Autowired
    private StringRedisTemplate stringRedisTemplate;

    @Autowired
    private ScriptEngineManager scriptEngineManager;

    /**
     * 抢购优惠券（原子操作）
     */
    @Transactional(rollbackFor = Exception.class)
    public Result<CouponGrabResult> grabCoupon(Integer couponStockId, Integer userId, Integer quantity) {
        // 1. 获取优惠券库存
        CouponStock stock = couponStockMapper.findById(couponStockId);
        if (stock == null || stock.getStatus() != 1) {
            return Result.error("优惠券已抢完或未开始");
        }

        // 2. 校验用户是否已抢购（防止重复）
        String userRecordKey = "coupon:record:" + userId;
        Boolean hasRecord = stringRedisTemplate.opsForSet().isMember(userRecordKey, String.valueOf(couponStockId));
        if (Boolean.TRUE.equals(hasRecord)) {
            return Result.error("您已抢购过该优惠券");
        }

        // 3. 执行 Lua 脚本（原子扣减库存）
        DefaultRedisScript<Long> redisScript = new DefaultRedisScript<>();
        redisScript.setScriptSource(new ResourceScriptSource(new ClassPathResource("lua/stock.lua")));
        redisScript.setResultType(Long.class);

        String stockKey = "coupon_stock:" + couponStockId;
        Long[] keys = {stockKey};
        Long[] args = {String.valueOf(userId), String.valueOf(quantity)};

        Long remainStock = stringRedisTemplate.execute(redisScript, keys, args);

        if (remainStock == null || remainStock < 0) {
            // 更新库存状态为已售罄
            updateStockStatus(couponStockId, 3);
            return Result.error("优惠券抢购失败，库存不足");
        }

        // 4. 扣减成功，插入用户优惠券记录
        UserCoupon userCoupon = new UserCoupon();
        userCoupon.setUserId(userId);
        userCoupon.setCouponTypeId(stock.getCouponTypeId());
        userCoupon.setCouponStockId(couponStockId);
        userCoupon.setStatus(0);  // 未使用
        userCoupon.setStartTime(new Date());
        userCoupon.setEndTime(calculateExpireTime(stock.getValidDays()));
        userCouponMapper.insert(userCoupon);

        // 5. 增加已使用数量
        couponStockMapper.incrUsedCount(couponStockId);

        // 6. 返回抢购结果
        CouponGrabResult result = new CouponGrabResult();
        result.setCouponStockId(couponStockId);
        result.setQuantity(quantity);
        result.setRemainStock(remainStock.intValue());
        result.setUserCouponId(userCoupon.getId());

        return Result.success(result);
    }

    private void updateStockStatus(Integer stockId, Integer status) {
        CouponStock stock = new CouponStock();
        stock.setId(stockId);
        stock.setStatus(status);
        couponStockMapper.update(stock);
    }

    private Date calculateExpireTime(Integer validDays) {
        return new Date(System.currentTimeMillis() + validDays * 24L * 60 * 60 * 1000);
    }
}
```

### 2. 瞬时流量控制（令牌桶算法）

**实现**：使用 Guava RateLimiter 或 Redis 令牌桶限流。

```java
@Service
public class CouponRateLimiter {

    @Autowired
    private StringRedisTemplate stringRedisTemplate;

    /**
     * 检查用户是否被限流（每分钟最多 10 次）
     */
    public boolean tryAcquire(Integer userId) {
        String key = "rate_limit:coupon:" + userId;
        Long count = stringRedisTemplate.opsForValue().increment(key);

        if (count == 1) {
            // 第一次访问，设置 1 分钟过期
            stringRedisTemplate.expire(key, 1, TimeUnit.MINUTES);
        }

        return count != null && count <= 10;  // 每分钟最多 10 次
    }
}
```

**Controller 层使用**：

```java
@RestController
@RequestMapping("/coupon/stock")
public class CouponStockController {

    @Autowired
    private CouponGrabService couponGrabService;

    @Autowired
    private CouponRateLimiter rateLimiter;

    @PostMapping("/{id}/grab")
    public Result<CouponGrabResult> grabCoupon(
            @PathVariable Integer id,
            @RequestBody GrabRequest request,
            @RequestHeader("Authorization") String token) {

        // 1. 验证 JWT
        Integer userId = JwtUtil.parseToken(token).get("id");

        // 2. 限流检查
        if (!rateLimiter.tryAcquire(userId)) {

        String idempotencyKey = request.getIdempotencyKey();
        if (StringUtils.isEmpty(idempotencyKey)) {
            idempotencyKey = UUID.randomUUID().toString();
        }
        String idempotentKey = "idempotent:coupon:grab:" + idempotencyKey;

        Boolean exists = stringRedisTemplate.hasKey(idempotentKey);
        if (Boolean.TRUE.equals(exists)) {
            return Result.error("您已抢购过该优惠券");
        }

        // 4. 执行抢购
        Result<CouponGrabResult> result = couponGrabService.grabCoupon(id, userId, request.getQuantity());

        // 5. 存储幂等键
        if (result.getCode() == 0) {
            stringRedisTemplate.opsForValue().set(
                idempotentKey,
                "granted",
                1, TimeUnit.HOURS
            );
        }

        return result;
    }
}
```

### 3. 数据库库存扣减（批量异步）

**核心思想**：Redis 预扣库存后，定时任务批量扣减数据库库存，保证最终一致性。

#### 定时任务实现

```java
@Component
public class CouponStockSyncTask {

    @Autowired
    private CouponStockMapper couponStockMapper;

    @Autowired
    private UserCouponMapper userCouponMapper;

    /**
     * 每 5 分钟同步一次 Redis 库存到数据库
     */
    @Scheduled(cron = "0 */5 * * * ?")
    public void syncStockToDatabase() {
        // 1. 获取所有库存缓存
        Set<String> keys = stringRedisTemplate.keys("coupon_stock:*");

        for (String key : keys) {
            try {
                // 2. 解析缓存 key 和剩余库存
                Long stock = Long.parseLong(key.split(":")[1]);
                String stockIdStr = key.split(":")[0].replace("coupon_stock:", "");
                Integer stockId = Integer.parseInt(stockIdStr);

                // 3. 查询数据库当前库存
                CouponStock dbStock = couponStockMapper.findById(stockId);
                if (dbStock == null) {
                    continue;
                }

                // 4. 对比 Redis 和数据库库存，修正差异
                if (dbStock.getRemainCount() != stock.intValue()) {
                    int diff = stock.intValue() - dbStock.getRemainCount();
                    if (diff > 0) {
                        // Redis 库存比数据库多，可能是预扣未同步，扣减数据库
                        couponStockMapper.decrRemainCount(stockId, diff);
                        log.info("库存修正: stockId={}, diff={}", stockId, diff);
                    } else if (diff < 0) {
                        // 数据库库存比 Redis 多，可能是超卖，回滚数据库
                        couponStockMapper.incrRemainCount(stockId, Math.abs(diff));
                        log.error("检测到超卖，库存回滚: stockId={}, diff={}", stockId, diff);
                    }
                }
            } catch (Exception e) {
                log.error("库存同步失败: {}", key, e);
            }
        }
    }
}
```

```java
@Component
public class GroupBuyProgressTask {

    @Autowired
    private GroupBuyMapper groupBuyMapper;
    @Autowired
    private GroupBuyRecordMapper groupBuyRecordMapper;
    @Autowired
    private StringRedisTemplate stringRedisTemplate;

    /**
     * 每 5 分钟更新一次团购进度
     */
    @Scheduled(cron = "0 */5 * * * ?")
    public void updateGroupBuyProgress() {
        // 1. 查询所有进行中的团购
        List<GroupBuy> groupBuys = groupBuyMapper.findByStatus(GroupBuyStatus.PROCESSING);

        for (GroupBuy groupBuy : groupBuys) {
            try {
                // 2. 统计当前参与人数
                int totalGroupSize = groupBuyRecordMapper.countByGroupBuyId(groupBuy.getId());

                // 3. 更新团购进度
                groupBuy.setProgressCount(totalGroupSize);

                // 4. 更新数据库
                groupBuyMapper.update(groupBuy);

                // 5. 删除缓存，下次查询时重新加载
                String cacheKey = "group-buy:" + groupBuy.getId();
                stringRedisTemplate.delete(cacheKey);

                // 6. 检查团购是否结束
                if (totalGroupSize >= groupBuy.getGroupSize() || groupBuy.getStatus() == GroupBuyStatus.CLOSED) {
                    finishGroupBuy(groupBuy);
                }
            } catch (Exception e) {
                log.error("更新团购进度失败: groupId={}", groupBuy.getId(), e);
            }
        }
    }

    /**
     * 团购结束处理
     */
    private void finishGroupBuy(GroupBuy groupBuy) {
        // 1. 更新团购状态为已结束
        groupBuy.setStatus(GroupBuyStatus.ENDED);
        groupBuyMapper.update(groupBuy);

        // 2. 通知所有参与用户（MQ + 短信）
        List<GroupBuyRecord> records = groupBuyRecordMapper.findByGroupBuyId(groupBuy.getId());
        for (GroupBuyRecord record : records) {
            mqProducer.sendGroupBuyFinishMessage(record.getUserId(), groupBuy);
        }

        log.info("团购结束: groupId={}, userIds={}",
            groupBuy.getId(),
            records.stream().map(r -> r.getUserId()).collect(Collectors.toList())
        );
    }
}
```

```java
@SpringBootTest
class CouponGrabConcurrentTest {

    @Autowired
    private CouponGrabService couponGrabService;

    @Test
    void testConcurrentGrab() throws InterruptedException {
        Integer couponStockId = 1;
        Integer quantity = 1;
        int threadCount = 100;  // 模拟 100 个用户并发抢购

        ExecutorService executorService = Executors.newFixedThreadPool(threadCount);
        CountDownLatch latch = new CountDownLatch(threadCount);

        AtomicInteger successCount = new AtomicInteger(0);
        AtomicInteger failCount = new AtomicInteger(0);

        for (int i = 0; i < threadCount; i++) {
            executorService.submit(() -> {
                try {
                    Integer userId = ThreadLocalRandom.current().nextInt(1000, 2000);
                    Result<CouponGrabResult> result = couponGrabService.grabCoupon(couponStockId, userId, quantity);

                    if (result.getCode() == 0) {
                        successCount.incrementAndGet();
                    } else {
                        failCount.incrementAndGet();
                    }
                } finally {
                    latch.countDown();
                }
            });
        }

        latch.await();
        executorService.shutdown();

        // 所有抢购都应该成功（假设总库存足够）
        assertEquals(threadCount, successCount.get());
    }
```

## 📈 性能优化建议

### 1. 数据库优化

- **索引优化**：为所有查询字段建立索引，特别是 `order_no`, `user_id`, `status`, `create_time`
- **分库分表**：订单表按用户 ID 或时间范围分表，避免单表数据量过大
- **读写分离**：主库写入，从库查询，减轻主库压力
- **慢查询优化**：定期分析慢查询日志，优化 SQL 语句

### 2. Redis 优化

- **集群部署**：使用 Redis Cluster 避免单点故障，提高并发能力
- **Pipeline**：批量操作使用 Pipeline 减少网络开销
- **过期策略**：合理设置 TTL，避免内存泄漏
- **监控告警**：监控 Redis 内存、QPS、命中率

### 3. 代码优化

- **异步处理**：订单支付、通知发送等耗时操作放入 MQ 异步处理
- **批量操作**：插入订单明细、扣减库存等使用批量操作
- **连接池优化**：配置合理的数据库连接池大小
- **缓存预热**：首页数据、热门商品等提前加载到 Redis

### 4. 前端优化

- **图片懒加载**：商品详情页长图使用懒加载
- **虚拟滚动**：商品列表使用虚拟滚动优化大数据量渲染
- **防抖节流**：搜索框输入、按钮点击等使用防抖/节流
- **CDN 加速**：商品图片使用 OSS + CDN 加速

## 🔐 安全性设计

### 1. 防刷策略

- **验证码**：抢购接口增加图形验证码，防止恶意刷量
